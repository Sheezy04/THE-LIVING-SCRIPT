- 许可证：https://creativecommons.org/publicdomain/zero/1.0/
- 本批图像是数据库扫描、描边或字体整理后提供的字样，不是完整甲骨、青铜器、简牍、碑刻或原拓照片。
- 每张图的著录、原图 URL、字形编号、查询参数、查询结果快照路径、尺寸、SHA-256 与日期保留在 `data/evidence.js`。

## 核验及重建

```powershell
node verify/test-evidence.mjs
node verify/collect-xiaoxue.mjs --cached
```

第一条只读核验：查询字头、元数据、著录、PNG chunk CRC、非空墨迹、图像哈希、隶变年代与小篆类型。第二条从本地查询快照重建数据，不访问网络；它会机械重写生成数据和对应缓存文件。

`node verify/collect-xiaoxue.mjs` 会重新执行公开查询并下载，仅用于维护；串行、有限、不登录、不使用付费接口、不绕过访问限制。服务端返回非成功状态会停止。

本批尚无专业人士对逐字释读作独立复核；程序检查不能证明所有历史解释正确。查询图的开放许可也不等于博物馆、权利人或学术机构认可本作品。

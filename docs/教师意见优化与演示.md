# 针对教师意见的优化与演示

本轮针对“是否只是文字展示、技术是否单一”的意见，将学习交互、DeepSeek 问答和构件挖掘连接到真实练习反馈。以下流程用于演示完整站点功能；AI 问答需要使用带后端的 Cloudflare 或 Node 服务地址。

| 教师关注点 | 当前功能与可验证依据 | 演示入口 |
|---|---|---|
| 大模型应用 | DeepSeek 根据项目资料回答，支持比较、追问、资料编号和出处跳转；巩固建议与看板可预填问题，用户确认后才发送 | 首页「让 AI 帮我理解」；看板「让 AI 解释相似与差异」 |
| 智能学习 | 记录最近 200 次实际作答，区分答对、未使用线索答对；按未巩固任务的重复次数推荐同类练习和资料回看 | 首页「下一步怎么学」；挑战完成后的复盘 |
| 数据挖掘 | 高频构件、保留重复次数的构件相似度、共现支持度／置信度／提升度；结果可下钻到具体汉字，再交给 AI 比较 | 07 语料看板 |
| 可视化 | 全站覆盖、缺口点阵、高频构件、相似推荐、五类个人练习表现；支持全屏和分析 CSV 导出 | 07 语料看板 → 全屏展示 |

## 4 分钟演示路线

1. **首页（30 秒）**：指出学习建议、AI 入口与看板入口，说明它们构成观察、练习、诊断和解释的流程。
2. **练习（1 分钟）**：完成一道题，或明确跳过一道拼合题。回到首页查看实际累计作答与待巩固建议；点击「同类巩固」进入对应题型。使用线索的正确回答会单独统计。
3. **挖掘与可视化（1 分钟）**：进入看板，选择高频构件「木」，查看该构件出现的具体汉字；选择「林」为比较起点，观察「森」及其他推荐字。查看个人练习表现，未练习维度应显示「尚未练习」。
4. **大模型（1 分钟）**：点击「让 AI 解释相似与差异」，确认预填问题后提问。查看回答引用的资料，并点击「查看字源展签」核对。
5. **收尾（30 秒）**：全屏展示看板，导出分析数据，说明模型回答、规则建议与原始资料分别提供什么依据。

## 可向老师说明

“项目已经加入资料检索增强的大模型问答、构件频率与相似度挖掘，以及可全屏展示的数据看板。这次进一步将它们接入学习流程：系统根据真实作答和未巩固笔记给出练习建议，用户可以回看对应资料、练同类任务，也可以把看板中发现的字组交给大模型解释，并核对回答出处。”

## 技术与数据边界

- 推荐基于明确的规则：优先重复次数较多、尚未巩固的任务；这是可解释的规则推荐，没有宣称训练了个性化模型。
- 练习统计只属于当前浏览器，最多保存最近 200 次作答，不能称为全站学习行为大数据。存储失败时保留本次页面的记录。
- 134 条目录中 38 条具备可分析的合体构件；默认至少两字共现时当前没有合格规则。如需演示一字探索，须同时展示小样本提示，不能把单字高置信度说成普遍规律。
- 构件相似不等于含义相同，现代构形不等于完整历史字源；缺失时期仍保持未收录状态。
- 所有问答请求沿用现有同域 API 和服务器密钥；打开建议只检查服务，点击「提问」才调用模型。

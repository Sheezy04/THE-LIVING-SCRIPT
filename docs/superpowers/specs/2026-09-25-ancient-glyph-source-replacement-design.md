# 古文字字形来源替换设计

日期：2026-09-25

## 目标与边界

《字启千年》参赛版不再使用授权范围尚未核实的中研院 CDP 2.4 字体衍生字形。对现有 396 个 CDP 2.4 格位，优先从汉典逐字页面「字源字形 → 字源演变」取得相同汉字、相同阶段的代表 SVG，真正替换轮廓与来源记录，而不是仅修改许可标签。无法确认字头、阶段、文件完整性或适用性的格位留空，不能回退到 CDP 2.4，也不能用现代字形伪装古文字。

作品仍保留 106 字目录和五阶段时间轴：甲骨文、金文、楚系简帛、战国金文、小篆。现有 103 格敬峰中山王篆（SIL OFL 1.1）及已核对的 9 格汉典 SVG 保留；新采集的汉典 SVG 覆盖四个原 CDP 阶段。现存 53 张小学堂 CC0 查询图片用于重点字的来源和断代交叉核对，不直接替代时间轴矢量，因为当前文件约 100 像素宽。小学堂站点目前对自动请求返回访问限制；不尝试绕过。

## 来源选择与权利表述

首选汉典，因其公开页面提供逐字、分阶段的字源演变图，且其服务条款公开作 CC0 1.0 归公声明：<https://zdic.net/terms/>。每格留存字条 URL、图像原始 URL、原始 SVG、SHA-256、采集日期、字头与阶段。汉典声明是该站的权利主张，不能保证全部上游第三方权利已清理；参赛说明须如实写明这一限制，不把汉典称为项目背书方。图像是数据库整理或描摹字形，不是出土原拓，也不单凭站点图形断言古文字释读已获专业复核。

不采用“将现有 CDP 2.4 改称 2.65/2.7”方案。中研院 2.65 版的公开许可不能自动覆盖本地 2.4 包；若将来另取确切新版字体，须单独验证取得途径、版本、具体文件、授权条件、字形映射和完整替换，属于后续独立工作。现有 CDP 2.4 本地原文件可保留作内部比对，但不得进入参赛版生成产物、页面展示或分发包。

## 数据流与文件职责

1. 专用采集脚本读取 `verify/roster.json` 的非关联字，逐字请求汉典公开字条，严格只解析「字源演变」代表图。将汉典的「甲骨文／金文／楚系简帛／说文」映射到项目四阶段。顺序采集并限速；403、429、访问限制、非 SVG 或页面结构变化时停止该批并报告，不登录、不绕过限制。使用已有本地原图时先验哈希，支持安全续跑。
2. 证据目录 `assets/evidence/zdic/` 保存每格原始 SVG 和机器可读清单；清单记录逐格 URL、阶段、哈希、校验状态和失败原因。现有 9 格并入统一清单。原 SVG 保留站方署名，不编辑其来源图；网页使用由源 SVG 转换、归一化后的路径。
3. `verify/build-ancient-data.py` 从已核验清单生成 `data/ancient.js`。CDP 字体不得作为构建输入或缺格回退。原有敬峰中山王篆仍按字体生成。`AncientGlyphs` 保持 `has`、`paths`、`erasOf`、`missingOf`、`glyphSource` 等运行时接口，并增加逐格证据查询所需的最小元数据。来源统计由实际生成结果计算，不写死 396 或 9。
4. 页面和参赛资料按真实结果显示来源、许可声明与缺格状态。汉典与小学堂是两套证据：不能把小学堂 CC0 授权套用到汉典 SVG；重点字交叉核对只记录同字同阶段的对应与差异，不能把异体差异误判成错误。

## 有效格位与失败处理

只有满足以下条件才进入时间轴：汉典字条与目录字对应；演变带的阶段标签精确匹配；源 URL 属于预期站点；HTTP 成功且内容为可解析 SVG；源图非空、有合理画布／路径；归一化后可以显示；逐格清单中 URL 与 SHA-256 可复查。若遇疑似拓片黑底、署名异常、阶段不明、来源混杂或文字学争议，则进入人工复核清单，在复核前不计入可用覆盖。站点页面展示了某个阶段，不代表该阶段已经完成学术释读验证。

采集成功后先比较旧、新覆盖。缺格要显示“此阶段未选得可核实字形”，而不是“历史上不存在”。无法安全获取的远程内容不强抓，保留明确的未完成清单。界面及报告中的覆盖率、满阶段字数、来源数量必须由生成数据计算，不能沿用旧统计。

## 验收与测试

- 先写失败测试，证明生成产物中任何旧 CDP 2.4 格位都会使测试失败；替换后运行同一测试验证为零。
- 对字条解析测试正常带、缺阶段、异常阶段、HTML 变更、非 SVG、空路径、错误字头与重复 URL；对源文件哈希和清单一致性测试篡改场景。
- 对生成结果测试每个实际存在的格位都有来源与证据；缺格不返回路径；保留五阶段接口与敬峰中山王篆格位。
- 检查重点字与现有小学堂资料的同字同阶段对应，记录可能的异体差异；对多个书体形态做可视化抽样，不用机械像素相等作为学术判断。
- 运行全项目既有验证套件及浏览器交互测试，修复来源统计引起的断言变化；检查原有 `verify/test-evidence.mjs` 的 396/405 旧统计断言。
- 交付逐格统计：成功替换、待复核、缺源、各阶段覆盖、旧 CDP 残留数及页面验证结果。不得在未验证全部格位时宣称“396 格全部替换”。

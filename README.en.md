# THE LIVING SCRIPT · 字启千年

An interactive exploration of Chinese character structure and representative historical glyphs. Open `index.html` for offline learning, or run `npm start` for the same-origin Node service with public DeepSeek Q&A. No build step or third-party server dependencies are required. See [deployment and AI setup](docs/公网部署与AI问答.md).

The experience has a home page and seven modules: character exploration, glyph evolution, structure lab, challenge, personal creation, a character relationship map, and a corpus dashboard. Visitors can inspect a character, manipulate components, create a digital glyph, and export a PNG poster or a transparent SVG.

The teaching catalog contains 134 entries. Of these, 106 have modern glyph outlines for the main interactive modules; the other 28 have meanings and relationships but no complete glyph set. The five historical-glyph categories contain 507 representative outlines across 530 candidate slots. Missing slots are shown as missing, not reconstructed. The separate evidence reader has selected reference examples for nine characters; its images are database query glyphs, not photographs of original artifacts. Three characters—木, 休, and 明—have deeper interpretive notes pending specialist review.

The project uses Vue, local SVG glyph paths, and Canvas. Seven learning modules work offline. Module 01 adds server-side DeepSeek Q&A: public visitors need no key, follow-up questions retrieve character facts again, and each answer displays its retrieved evidence. The server reads its key from an environment variable and limits requests. The visitor interface offers questions, follow-ups, and reference material; connection settings and model configuration are managed on the server. Module 07 adds component frequency mining, multiset Jaccard recommendations, exploratory co-occurrence rules, fullscreen presentation, and CSV export. Third-party assets, licenses, and usage limits are documented in [the asset inventory](assets/vendor/LICENSES.md). Historical glyphs remain representative selections; model answers require verification and personal creations are digital artworks.

Earlier development notes in the Chinese README may describe historical states. For the current running experience, start with `index.html` and the asset inventory above.
